# Storyboard｜績效謎案：福義軒資金失蹤事件簿

這份 storyboard 是把來源簡報重新編排成互動網站的敘事設計，不是投影片逐頁複製。主軸採「提問 → 反差 → 線索 → 比較 → 行動 → 預期結果」的累積式閱讀。

## 敘事主張

讀者在離開網站前，應理解：生產效率表面穩健，不代表資金流速健康；來源簡報指出的庫存週轉、包材同步與呆滯料問題，必須用止血、流程同步、結構調整三階段回應。

## Section 流程

| 網站 Section | 敘事任務 | 來源投影片 | 互動語言 |
| --- | --- | --- | --- |
| Hero | 建立電影感問題與調查入口 | 1 | 全螢幕 AI 背景槽、文字分層進場、首屏 CTA |
| Story | 先承認生產端優勢，再拉出 4.9 天的資金流速異常 | 2–6 | 三段敘事節拍、ScrollTrigger reveal、留白與直線進度 |
| Evidence | 將三個庫存問題變成三條證據線索 | 7–9 | 雜誌式大卡片、證據視覺槽、Parallax、數據逐項揭露 |
| Compare | 將「成本下降／庫存上升」的負向背離具體化 | 4–5、8 | 比較板、條形展開、原值 HTML 標示 |
| Timeline | 以三個行動階段取代投影片逐張閱讀 | 11–14 | 垂直時間線、ScrollTrigger rail、階段內容進場 |
| Dashboard | 呈現來源簡報提出的預期戰果 | 15 | GSAP counter、三欄資料視覺、預期語意標示 |
| Ending | 回答 Hero 問題，留下行動出口 | 16 | 背景影像槽、收束文字、回到案件入口 |

## 視覺方向

- 整體：深色電影感、低飽和藍紫色光源、玻璃層與細線網格。
- 影像：六個主要場景使用同一套 2.5D 擬人化芝麻蛋捲、烘焙餅乾與食品廠角色；背景只放無文字 AI 影像，標題、數據與敘事均為 HTML。
- 角色：蛋捲與餅乾負責帶讀者穿過烤箱、冷卻、包裝、倉儲與出貨；包材用停滯姿態呈現庫存問題，經營者角色承接 Dashboard 的決策視角。
- 節奏：Hero 慢、Evidence 有重量、Compare 清楚、Timeline 具方向性、Dashboard 有「戰果」感。
- RWD：桌面使用雙欄與大字級；平板收斂間距；手機改為單欄堆疊並保留閱讀順序。

## 來源資料處理

網站沒有將來源簡報中的內容擴寫成新的事實。簡報中若使用「目標」、「預估」、「可能」等語氣，網站也保留同等不確定性；未來補入 Markdown 或新的 PPT 時，請同步更新內容合約與數據來源註記。
