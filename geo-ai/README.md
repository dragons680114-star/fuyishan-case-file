# 福義軒 GEO 反思互動簡報

16 頁、16:9 全螢幕 HTML 互動簡報。所有文字為 HTML；底圖均為本案生成的 2.5D 概念畫面。

## 開啟方式

直接雙擊 `index.html` 即可開啟。報告時可使用右下角的「全螢幕」按鈕，或按瀏覽器的 `F11`。

- `←` / `→`：上一頁、下一頁
- `空白鍵`：下一頁
- `Home` / `End`：第一頁、最後一頁
- 第 2 頁：點選三個提問，切換觀察結果。
- 第 7 頁：點選四個條件，切換白話說明。

## 資料夾

- `assets/images/`：每頁 2.5D 底圖。
- `css/deck.css`：全螢幕、字級、響應式與動畫樣式。
- `js/deck.js`：換頁、鍵盤、全螢幕與頁內互動。
- `docs/STORYBOARD.md`：逐頁說故事與畫面設計。
- `sources.md`：使用者資料、編輯轉譯與待補事項。
